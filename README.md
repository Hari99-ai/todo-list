# 📝 To-Do List 

This is a simple command-line To-Do List application written in Python. It allows users to add, view, complete, and delete tasks from their list using a terminal interface.

---

## 🚀 Features

- ✅ Add new tasks  
- 📋 View all tasks with their completion status  
- ✔️ Mark tasks as completed  
- ❌ Delete tasks  
- 🔁 Looping menu for continuous use  
- 📦 No external dependencies – runs with pure Python
